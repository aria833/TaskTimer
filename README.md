TaskTimer

一個簡單好用的任務計時器，幫助你記錄每天花在不同任務上的時間。

TaskTimer 採用 Local-first 設計，不需要註冊或登入，打開網頁就可以開始使用。你可以建立任務、開始計時，並在完成後查看自己的時間紀錄，慢慢了解自己的學習與工作節奏。

🌟 核心功能 (Features)

- 任務計時：簡單直覺地開始與結束計時，輕鬆記錄每項任務花了多少時間。
- 任務管理 (CRUD)：可以新增、編輯、刪除與查看任務，讓任務清單保持整齊。
- 多語系支援 (i18n)：支援繁體中文、英文與日文，可以依照自己的習慣切換語言。
- 本地優先 (Local-first)：資料會儲存在瀏覽器本地，不需要登入帳號，也能安心使用。
- 資料備份與還原：可以將資料匯出備份，之後再還原回 TaskTimer，方便保存自己的紀錄。

🛠️ 使用技術 (Tech Stack)

- 核心語言：Vanilla JavaScript (ES6+)
- 建置工具：Vite
- UI 框架：Bootstrap 5
- 資料儲存：IndexedDB / Web Storage API
- 自動化部署：GitHub Actions & GitHub Pages
